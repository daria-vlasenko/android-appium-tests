# Android Appium Tests

Автотесты нативного Android-приложения на Appium 2 + UiAutomator2, прогон на эмуляторе.

Акцент проекта — **мобильная специфика**: жесты, системные диалоги, жизненный цикл приложения, поведение без сети. То, чего не бывает в вебе.

Тестируемое приложение: [My Demo App](https://github.com/saucelabs/my-demo-app-rn) — открытое демо Sauce Labs. Дополнительный блок — мобильный веб [ParaBank](https://parabank.parasoft.com/parabank/index.htm) в Chrome на эмуляторе.

Смежные репозитории портфолио: [parabank-ui-tests](https://github.com/daria-vlasenko/parabank-ui-tests) (веб, Selenide), [conduit-api-tests](https://github.com/daria-vlasenko/conduit-api-tests) (API, REST Assured), [java-testing-practice](https://github.com/daria-vlasenko/java-testing-practice) (unit, JUnit 5 + Mockito).

> **Статус: в работе.** Репозиторий создан 13.09.2026, ниже — план покрытия. Отмеченные пункты реализованы.

## Стек

|---|---|
| Java 17 | язык |

## Покрытие

**Базовые сценарии**
- [ ] Вход с валидными данными
- [ ] Вход с неверным паролем — сообщение об ошибке
- [ ] Каталог товаров отображается
- [ ] Открытие карточки товара
- [ ] Добавление в корзину, счётчик обновляется
- [ ] Удаление из корзины
- [ ] Оформление заказа до экрана подтверждения

**Мобильная специфика**
- [ ] Скролл до элемента за пределами экрана
- [ ] Свайп по галерее изображений товара
- [ ] Длинное нажатие
- [ ] Поворот экрана — состояние не теряется
- [ ] Сворачивание и возврат из фона
- [ ] Обработка системного диалога разрешений
- [ ] Поведение при отключённой сети

**Мобильный веб**
- [ ] Вход в ParaBank через Chrome на эмуляторе
- [ ] Перевод между счетами
- [ ] Адаптивная вёрстка на узком экране

## Чем мобильная автоматизация отличается от веба

- **Локаторы**: `accessibility id`, `UiAutomator`, XPath. CSS-селекторов нет.
- **Жесты**: свайп, длинное нажатие, скролл — отдельный API, а не клик по координатам
- **Ожидания сложнее**: анимации переходов между экранами добавляют недетерминированность
- **Разрешения**: системные диалоги перехватывают фокус и ломают сценарий
- **Фрагментация**: версии Android, размеры экранов, производители
- **Прерывания**: звонок, сворачивание, возврат из фона, поворот

## Структура

```text
src/main/java/com/mobile/
├── config/     capabilities, адрес сервера Appium
├── screens/    Screen Object — по классу на экран
└── data/       генерация тестовых данных

src/test/java/com/mobile/tests/
├── BaseTest    поднятие драйвера, listener Allure
└── *Tests      сценарии
```


## Требования к окружению

- Android Studio + Android SDK
- Эмулятор (AVD), Android 12 или 13
- Node.js + Appium Server 2.x
- Драйвер UiAutomator2
- APK приложения из [релизов](https://github.com/saucelabs/my-demo-app-rn/releases)

## Запуск

```bash
appium                  # в отдельном терминале: поднять сервер
mvn clean test          # прогон
mvn allure:serve        # отчёт
```
